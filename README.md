# BMI Calculator Using Python

A simple BMI Calculator built using Python in Jupyter Notebook.

## Project Overview

This project calculates a user's Body Mass Index (BMI) using their weight and height, then classifies the result into different BMI categories.

The calculator takes the user's name, weight in pounds, and height in inches as inputs. It then calculates BMI using the formula:

**BMI = (weight × 703) / height²**

## Features

* Accepts the user's name as input
* Accepts weight in pounds
* Accepts height in inches
* Calculates BMI using Python
* Classifies the BMI result using conditional statements
* Displays a personalised result based on the calculated BMI
* Handles BMI values of zero or below as invalid input

## Technologies Used

* Python
* Jupyter Notebook

## Python Concepts Used

* User input with `input()`
* Variables
* Arithmetic calculations
* Conditional statements
* `if`, `elif`, and `else`
* Formatted output

## How It Works

1. The user enters their name.
2. The user enters their weight in pounds.
3. The user enters their height in inches.
4. The program calculates the BMI.
5. Conditional statements classify the BMI result.
6. The program displays the corresponding result.

## Example

```text
Enter your name: Leonard
Enter the weight in pounds: 154
Enter the height in inches: 70

BMI: 22.10
Leonard, you are in the normal range.
```
